# Правила дизайна

- Используй Tailwind CSS для цветовой палитры и классов.
- Выстраивай визуальную иерархию с помощью типографики, пространства и цвета. Избегай случайных градиентов, чрезмерного свечения и лишнего декора.
- Выноси базовые и повторяющиеся элементы интерфейса, например кнопки, поля ввода и чекбоксы, в переиспользуемые компоненты. Если шапка или подвал используются на нескольких страницах, выноси их в общие составные компоненты.
- Пиши подписи секций и короткие пометки над заголовками в обычном регистре. Сохраняй стандартный межбуквенный и межстрочный интервалы, не используй верхний регистр для выделения.
- В обычном и компактном чате сохраняй постоянную мягкую подсветку за полем ввода. Используй один акцентный цвет `amber-400` (`#FBBF24`) с низкой непрозрачностью. Подсветка остаётся статичной при вводе, ожидании ответа и ошибке.
